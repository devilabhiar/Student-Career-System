# Student Career System

## Overview
Student Career System is a web-based application developed to help students identify suitable career opportunities based on their skills and interests. The system allows students to manage their skills and receive career guidance, while administrators can manage career suggestions and student records.

## Features

### Student Module
- Student Registration
- Student Login & Logout
- Session Management
- Add Skills with Skill Level
- View Career Suggestions
- Resume Generation
- Forgot Password & Reset Password

### Admin Module
- Admin Login & Logout
- View Registered Students
- View Student Skills
- Add Career Suggestions
- View Career Suggestions
- Delete Career Suggestions
- Delete Student Records
